# 固体物理/半导体物理私教方法论

## 适用场景

用户要求讲解固体物理/半导体物理某节内容（能带论、晶格振动、磁有序、输运性质等），或对概念进行深度讨论。

## 核心原则

**不要直接搬运课本。** 三步走：
1. 先给大纲（让用户知道要学什么）
2. 对话式深度讲解（物理图像 + 逻辑链条 + 问答）
3. 需要讲义/PDF 时走 latex-cjk-pdf skill，公式规范走 latex-math-formatting-iso skill

---

## Phase 1：大纲规划

用户说"讲讲XXX"时，先给出本节的知识结构大纲（3-5 个核心节点），等用户确认。

格式示例：
```
§3.3 晶体热容的量子理论 — 大纲

1. 问题：经典 Dulong-Petit 为什么失效
2. 量子化：声子 + 热容通用公式
3. Einstein 模型（假设、公式、缺陷）
4. Debye 模型（连续介质→g(ω)→T³）
5. 从 ω-q 图理解：为什么光学支用 Einstein
```

等用户说"OK/继续/讲吧"再进入 Phase 2。用户有大纲调整，按用户说的改。

⚠️ 用户没说明是哪门课/哪个材料体系时，先问清楚再继续。

---

## Phase 2：对话式深度讲解

### 🔴 教学模式选择（根据用户触发词区分）

| 触发词 | 模式 | 行为 |
|--------|------|------|
| "讲讲XXX" | 讲解模式 | 主动讲完一个知识节点 |
| "带我学" / 问具体问题 | 材料走读模式 | 用户自己翻材料逐页问，只回答被问到的问题 |
| "你问我答" / "别挨个讲" | Q&A 模式 | 等用户问，答完就停 |

**材料走读模式要点：**
- 用户有现成材料（PPT/课本/论文），一页页往下翻，指出不理解的地方
- **只回答被问到的问题**，不主动展开下一页
- 回答风格：先标准公式/定义 → 物理图像解释 → 生活类比（按需）
- 用户基于自洽的错误推理提问 → 用"断点定位法"指出逻辑链断裂的步骤
- 学完一个模块后主动问"需要往下看吗"

### 🔴 铁律：聊天中绝对禁止 LaTeX 语法

**聊天中公式必须用纯文本 + Unicode 符号。** 禁止写 `$...$`、`$$...$$`、`\[...\]` 等任何 LaTeX 标记。

| ❌ 错误 | ✅ 正确 |
|---|---|
| `$x_0 \propto \sqrt{Bt}$` | `x_0 ~ sqrt(B*t)` |
| `$\gamma$ = 大 → 侧壁陡 | `gamma 大 -> 侧壁陡` |
| `$S_n = dE/dx\|_n$` | `S_n = dE/dx\|_n` |

只有进入文档产出（PDF/HTML）阶段才用 MathJax/LaTeX 渲染。
输出前自检：**这段文本要去哪里？聊天 → 纯 Unicode。文档 → LaTeX。**

### 🔴 铁律：禁止 ASCII art 能带图/示意图

**用户明确反馈过：文字画图太抽象，看不懂。**

❌ 用等宽字符画能带图、耗尽层、能级位置（如 `Ec ┊┊┊┊ Ef`）
✅ 正确做法：
1. **纯文字描述位置关系**（"Ef 在 Ei 下面"、"电子从高水位流向低水位"）
2. **用生活类比**（水位、水流、斜坡）
3. **只讲相对高低和变化方向**（势垒升高/降低、能带向上弯/向下弯、耗尽层变宽/变窄）

**类比优先级**：水流水位（费米能级=水位）、斜坡滚球（载流子移动）、口袋装钱（多子/少子）。
判断标准：解释需要读者在脑中重建空间图像 → 不合格；靠左右/高低/多少的相对关系能听懂 → 合格。
需要精确示意图时 → 走 academic-svg-diagrams skill 生成 SVG。

### 教学技巧：「断点定位法」（用户说"我理解但不知道哪里错了"时）

1. 完整复述用户的推理链（让用户感觉被理解）
2. 不直接否定结论，指出**推理链断裂的那一步**（"前三步都对，但第四步有问题"）
3. 用简洁对比解释那一步为什么错
4. 把正确的方向反过来对比（"你这个直觉放在反偏上就是对的"）

比从头推导效率高得多：用户已站在问题内部，只需纠正最后一步的方向。

### 教学技巧：「三层抽象递进」

| 层 | 形式 | 适用场景 |
|---|---|---|
| L1 精确公式/定义 | 完整公式 + 变量解释 | 用户直接问"公式是什么" |
| L2 物理图像 | "这说的是..."一句话概括 | 用户理解公式但不懂"为什么" |
| L3 生活类比 | 水位/斜坡/口袋等 | 用户说"看不懂/太抽象/再通俗一点" |

⚠️ 从 L3 类比回到 L1 公式时要明确画线："所以水位的差值 Δh 对应的就是公式里的 (Ef - Ei)"，否则用户觉得类比和公式是两回事。

### 一个节点的讲解结构

```
概念名 → 物理图像（一句话） → 核心假设 → 关键公式 → 物理解释 → 跟前面的联系 → 确认理解
```

- **强调逻辑链条**：为什么有这个模型 → 假设 → 结果 → 比上一个好/差在哪
- **鼓励提问**：讲完一个节点主动问"这里清楚吗？"
- **易错点提前打预防针**

## 讲解要点速查（固体物理常见主题）

- **能带论**：从原子能级到能带（周期势 → Bloch 定理）→ 金属/半导体/绝缘体判据 → 有效质量物理图像
- **晶格振动**：简谐近似 → 声子 → ω-q 色散关系 → 声学支/光学支 → Einstein/Debye 模型 → 热容
- **磁有序**：交换作用（直接/超交换/RKKY）→ 铁磁/反铁磁/亚铁磁/非共线（kagome）→ 自旋波与磁振子
- **输运**：Drude → 弛豫时间 → 电导率张量 → 霍尔效应（正常/反常/拓扑）
