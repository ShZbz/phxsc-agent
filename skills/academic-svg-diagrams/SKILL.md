# 学术 SVG 示意图 — 工作流与约定

## 核心原则

1. **几何优先，样式其次**：每个坐标必须先数学验证，再上颜色/标注。
2. **绝不目测坐标**：数值计算 → 数学验证 → 写 SVG。
3. **SVG 几何复杂时，用浏览器打开检查**：肉眼查错比读代码可靠。
4. **用浏览器开发者工具检查 SVG 元素坐标**：`document.querySelectorAll('line, path')` 可拿精确数据。

## 通用约定

- `viewBox` 周围留充足边距
- 独立图形优先内联 SVG（无外部文件）
- 用语义化 `<!-- 注释 -->` 记录坐标计算过程
- 绘制层序：隐藏层（虚线/灰）→ 填充 → 可见层（实线）→ 标注
- 半透明面填充在边线**之前**画

## Bragg 衍射图

### 几何规则
- **θ 弧**：位于入射点**左侧**，晶面（水平）与入射光线（指向光源，左上方）之间。用 `sweep=1`（SVG 顺时针）。
- **2θ 弧**：入射（左上方来）与反射（右上方去）之间，**穿过顶部**。用 `sweep=1`。
- 两条入射光线必须平行（同斜率），两条反射光线也必须平行。
- 光程差 `PB = BQ = d·sinθ`，P 是下光线上波前交点，B 是下入射点，Q 是反射波前交点。

### 双光线几何布置（已验证）
```
Plane 1 在 y₁，Plane 2 在 y₂ = y₁+d（d = 晶面间距）
θ = 30°，tanθ = 0.577，sinθ = 0.5
Ray 1 打 Plane 1 于 A，Ray 2 打 Plane 2 于 B
两光线打在相同 x（B 在 A 正下方）
P = 过 A 垂直入射方向的波前，交 Ray 2
Q = 过 A 垂直反射方向的波前，交 Ray 2 反射线
PB = BQ = d·sinθ
```

## 3D 晶体坐标系

### 六棱柱绘制
六方晶系（a₁, a₂, a₃, c）：

**最佳投影：planometric（屏幕上正六边形）**
- 顶面：屏幕上的正六边形——保持 120° 角在屏幕可见
- 底面：同形向下平移
- 对应顶点用竖直边连接

**备选：斜二测（cabinet oblique）**
- 正面矩形真实尺寸，深度 45° 收缩、比例 0.5
- ⚠️ **缺点**：3D 里的 120° 角在屏幕上不再是 120°——角度可见性重要时禁用

### 顶点命名约定
```
V0~V5（逆时针，底面）
V0'~V5'（对应顶面）
Center = 底面六边形中心
```

### 可见性规则（planometric 从前右看）
| 边类型 | 可见（实线） | 隐藏（虚线） |
|--------|-------------|-------------|
| 底边 | V4-V5, V5-V0, V0-V1 | V1-V2, V2-V3, V3-V4 |
| 顶边 | V4'-V5', V5'-V0', V0'-V1' | V1'-V2', V2'-V3', V3'-V4' |
| 竖边 | V4-V4', V5-V5', V0-V0' | V1-V1', V2-V2', V3-V3' |

### 坐标轴
- **a₁**：底面中心 → V0（右，0°）
- **a₂**：底面中心 → V2（planometric 中自 a₁ 逆时针 120°）
- **a₃**：底面中心 → V4（自 a₂ 逆时针 120°）
- **c**：底面中心 → 正上方
- 箭头必须**指向顶点**（箭尖在顶点，翼向后指向中心）

### 120° 角标记
- 所有弧圆心在底面中心
- 三个弧用一致半径
- 弧序：a₁→a₂（经顶）、a₂→a₃（经左）、a₃→a₁（经底），每弧 120°
- 经顶/左/底的弧用 `sweep=0`（屏幕上逆时针）

## SVG 调试工作流

图看起来不对时：
1. **本地起服务**：`python3 -m http.server <port> --bind 127.0.0.1`
2. **浏览器打开**检查视觉
3. **控制台取元素**：提取所有 line/path 元素的精确坐标
4. **数值复核**：对照预期几何重算坐标
5. **外科式修复**：patch 单个元素，不要整图重画

## 陷阱

- SVG 弧 sweep 方向：`sweep=0` = 屏幕逆时针（先减 y），`sweep=1` = 顺时针。搞反弧就反着画。
- 斜二测里的 120° 弧：屏幕上投影角不是 120°——角度可见性重要时用 planometric。
- Bragg 图光程差三角形：晶面间**竖直**距离是 d，`PB = d·sinθ` 沿光线方向，**不是水平方向**。
- 箭头多边形必须沿轴向前，翼向后指中心。
- 灰虚层 + 蓝虚层 = 冗余，隐藏边只用一种。
