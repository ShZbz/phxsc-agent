# 学术文件排版格式规范

> 来源：GB/T 7713.2-2022、GB/T 7714-2015/2025《参考文献著录规则》、Nature Portfolio 格式指南、IEEE 模板。
> 正文引用格式（Author et al. 格式）见 citation-format skill；本 skill 管版式与参考文献表。

---

## 一、学术论文 / 实验报告（正式版）

**适用：投稿期刊、学位论文、正式实验报告**

### 1.1 页面设置
| 项目 | 规格 |
|------|------|
| 纸张 | A4 (210×297 mm) |
| 页边距 | 上2.5cm、下2.5cm、左2.5~3.0cm、右2.5cm；装订线 0.5cm 左侧 |
| 行距 | 1.5 倍（正文）；单倍（目录/摘要/参考文献） |
| 页码 | 从正文开始编号，宋体五号居中/右下 |

### 1.2 字体字号
| 层级 | 中文 | 英文/数字 | 字号 |
|------|------|-----------|------|
| 论文题目 | 黑体加粗 | Times New Roman | 二号(22pt)/小二号(18pt) 居中 |
| 一级标题 | 黑体加粗 | Times New Roman | 三号(16pt) |
| 二级标题 | 黑体加粗 | Times New Roman | 小三(15pt)/四号(14pt) |
| 三级标题 | 黑体加粗 | Times New Roman | 小四(12pt) |
| 正文 | 宋体 | Times New Roman | 小四(12pt)，两端对齐，首行缩进 2 汉字 |
| 摘要 | 宋体 | Times New Roman | 小四，200~300 字 |
| 关键词 | 宋体 | Times New Roman | 小四，3~8 个，分号分隔 |
| 图/表标题 | 宋体 | Times New Roman | 五号(10.5pt)，图下表上，居中 |
| 参考文献 | 宋体 | Times New Roman | 五号，悬挂缩进 |

### 1.3 标题层级与编号
- 理工类：**第1章** → **1.1** → **1.1.1** → **(1)** → **①**
- 文经管类：**一、** → **(一)** → **1.** → **(1)** → **①**

### 1.4 参考文献表（GB/T 7714-2015/2025）
- 正文引用：`[1]` 内联或 `\textsuperscript{[1]}` 上标；按出现顺序编号
- 作者规则：3 个以内全写，超 3 个加"等"/"et al"；西文姓全大写名缩写（`Einstein A`），汉语拼音姓全大写（`LI Jiangning`）

**文献类型标识（2025 版）**：
| 类型 | 标识 | 类型 | 标识 |
|------|------|------|------|
| 普通图书 | M | 期刊文章 | J |
| 会议录 | C | 网站/网页 | EB |
| 学位论文 | D | 预印本 | PP（新增） |
| 报告 | R | 数据集 | DS（新增） |
| 标准 | S | 专利 | P |

**示例**：
```
[1] 王利平, 王福新, 刘洪. 过冷大水滴环境粒径分布模拟方法研究进展[J]. 航空学报, 2024, 45(增刊1): 730570.
[3] Li J, Zhang H. Topological Hall effect in Mn₃Sn kagome magnet[J]. Nat Commun, 2023, 14: 12345.
```

### 1.5 公式与图表
- 公式居中，编号 `(1)`/`(1.1)` 右对齐；变量斜体、常数直体（见 latex-math-formatting-iso skill）
- 图题在图下、表题在表上；表格用三线表（顶线、表头线、底线）
- 图分辨率 ≥ 300 dpi；图内标注 5~7pt sans-serif

### 1.6 国际期刊要点
| 期刊 | 要点 |
|------|------|
| Nature | 双倍行距；摘要≤200词；物理 6 页；≤50 参考文献；12pt Times |
| IEEE | 双栏；标题 24pt；正文 10pt；摘要 150~250 词 |

## 二、学术论文 / 实验报告（日常版 — 美观优先）

**适用：课程实验报告、内部交流、非正式文档**

| 项目 | 规格 |
|------|------|
| 页边距 | 上下左右 2.0cm |
| 行距 | 1.3~1.5 倍 |
| 标题 | 思源黑体/黑体，一级 16~18pt、二级 14pt、三级 12pt，深蓝 #2B3A67 |
| 正文 | 思源宋体/宋体 11pt |
| 代码/公式 | JetBrains Mono / Times New Roman 10pt |
| 参考文献 | 格式统一即可（不必严格 GB/T 7714），所有文献含 DOI |

**配色**：主色 #4A90D9（蓝）、强调 #E74C3C（红）、灰 #95A5A6，不超 2 色。

## 三、学术 PPT

### 3.1 正式版要点
| 项目 | 规格 |
|------|------|
| 比例 | 16:9 |
| 标题 | 黑体/Arial Bold 24~28pt，**action title**（完整句子说明该页要点） |
| 正文 | 18~20pt，最小 14pt |
| 配色 | 白底深字（正式场合） |

**Action Title 规则（核心）**：每页标题是完整陈述句，不是主题标签。
❌ "Results" → ✅ "Treatment effect is significant across all three cohorts"

**结构**：标题页 → Outline → 研究问题（第 2~3 页必须提出）→ 背景（已知→未知→本工作）→ 方法 → 结果（每页一个核心发现，图左解读右）→ 总结 → 致谢/参考文献

**图表与文本**：
- 每页一个核心图表；图/表标注 ≥ 16pt；不直接从论文 PDF 截图（重建原生图形）
- 每页正文 ≤ 40 词、≤ 5 要点，电报式语言
- 当场引用右下角小字：`Author et al., Journal Volume, FirstPage`（同 citation-format skill）

### 3.2 日常版（美观优先）
- 主色 #4A90D9 + 灰 #95A5A6，标题 28~32pt，正文 20~24pt 1.3 倍行距
- 浅灰渐变或纯白偏暖背景，扁平图标，圆角卡片容器
- 标题区固定位置，页码右下 10pt 灰色
