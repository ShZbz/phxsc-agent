# 综述写作规范

## 结构框架

1. **引言**：领域背景 + 为什么现在写这篇综述（最近 2-3 年的进展动力）+ 综述范围声明（覆盖哪类材料/哪个时间窗）。
2. **分类组织**：按机理/材料体系/方法三条主线之一组织，不按论文罗列。每小节：先给分类逻辑，再讲代表工作，最后小结该路线的优缺点。
3. **比较视角**：至少一处直接对比（表格式最佳）——不同材料体系的稳定性对比、不同增强策略的优劣对比。
4. **挑战与展望**：未解决问题要具体（不是"仍需深入研究"空话），给出可能的解决方向。

## 写作纪律

1. **证据密度**：每段至少 1 个具体引用（格式见 citation-format skill）；"有研究表明"必须换成具体文献。
2. **区分层次**：综述已有结论 vs 你的批判性评价要分开（原文结论 → 你的看法，两段式）。
3. **术语统一**：同一概念全文一个译名/缩写，首次出现给全称。
4. **量化优先**：能用数字（效率 30%、T90 稳定性 500h）不用形容词。
5. **时间线意识**：标注工作年份，展示领域演进（"2023 年 X 提出...，2025 年 Y 改进..."）。
6. **不堆砌**：每个小节 3-6 篇代表文献足够，宁缺毋滥。

## 输出格式

- 长综述：分段输出（可分批），每批末尾给"已覆盖/待覆盖"进度提示
- 短综述（<2000 字）：一次成稿，附文献清单（作者/年份/期刊/核心贡献一句话）

## 自检清单（输出前）

- [ ] 每段有具体引用？
- [ ] 有直接对比（表或段落）？
- [ ] 展望部分具体不空泛？
- [ ] 综述结论与个人评价已分开？
