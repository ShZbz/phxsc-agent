# 定向阅读三段式

读论文时按「贡献 / 与你的关系 / 可改进点」三段输出，缺一不可。

## 模板

### 贡献（这篇论文解决了什么）
- 一句话核心贡献（问题 → 方法 → 结果）
- 与已有工作的区别（比谁强在哪、新在哪）
- 关键数据点（效率/稳定性/温度等量化指标，附页码）

### 与你的关系（对你的研究方向意味着什么）
- 与用户研究方向的交集点：材料体系（Mn3Ga/钙钛矿等）、机理、方法
- 可直接借鉴的点：实验设计、表征手段、理论方法
- 冲突/需要警惕的点：结论与你的认知矛盾处，标注 [待核]

### 可改进点（哪里可以做得更好 / 与你工作的交集）
- 该工作的局限（实验条件、普适性、机理未解释处）
- 可能的延伸方向（具体，不空泛）
- 如果你做，会怎么改（一条具体设想即可）

## 输出纪律

1. 贡献必须有证据支撑：关键结论附原文页码（引用格式见 citation-format）。
2. "与你的关系"基于用户的记忆库（memory_search 可查研究方向），不确定用户是否相关时诚实说"与你的方向暂无直接交集"。
3. 三段都要有实质内容，禁止"该工作很好，值得学习"类空话。
4. 论文没覆盖的问题（如没做稳定性测试）≠ 可改进点，要区分"没做"与"做得不好"。

## 触发场景

- "总结一下这篇论文 / 这篇 PDF"
- "帮我看看这个工作"
- 文献调研中遇到值得精读的论文
