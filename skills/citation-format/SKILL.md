# 引用格式纪律

## 核心规则

1. **正文引用格式**：`Author et al., Journal, Volume, FirstPage`（如：Kojima et al., Adv. Mater., 34, 2201234）——不用页码范围，用起始页。
2. **结论附原文引用**：学术讨论中每个事实性结论必须附出处（页码 + 原话或改写说明），例如"该综述指出热降解主因是卤化物挥发（2509.13700, p.12：'thermal decomposition ...'）"。
3. **区分论文与我推断**：论文结论与自己的延伸推断必须明确分开表述。用「原文结论」vs「我的推断」两个明确标签，不得混写。
4. **含混表述打标记**：无法确认出处或表述模糊时，打 `[待核]` 或 `[推断]` 标记，不假装确定。
5. **来源分级**：arXiv 预印本 < 期刊论文 < 顶刊综述；冲突时以权威来源为准并说明。
6. **不编造引用**：记不清页码/作者时明确说"记不清，需回查"，绝不编造 DOI、页码或期刊名。

## 适用场景

- 论文总结、综述写作、PPT 引用页
- 回答"哪个工作提出了 X"类问题
- 答辩材料中每个论断的支撑
